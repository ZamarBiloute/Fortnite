Gameplay du jeu

L'essence même du jeu est de pouvoir se mouvoir sur une carte avec armes en main afin d'e^tre le dernier en vie. Mais comment faire avec ces conditions? Comment se déplacer dans ce monde? Comment fonctionne les armes ou encore comment on peut se battre avec du panache? C'est ce que nous allons voir ensemble dans cette page. Nous allson donc vous présenter les éléments principaux de chacune de ces catégories.
